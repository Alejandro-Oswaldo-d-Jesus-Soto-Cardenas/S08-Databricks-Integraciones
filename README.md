
# S08 - Databricks e Integraciones

**Estudiante:** Alejandro Oswaldo de Jesús Soto Cárdenas

**Curso:** Databricks e Integraciones

## Objetivo

Implementar la integración de GitHub con Databricks mediante
GitHub Actions, configurar conexiones externas, utilizar
Databricks CLI y administrar archivos con Unity Catalog.

## Tecnologías

- Databricks
- Python y PySpark
- GitHub Actions
- Databricks CLI
- Unity Catalog

## Estructura

- data/: archivos CSV de usuarios
- notebooks/: notebooks de análisis en PySpark
- .github/workflows/: pipeline de GitHub Actions

## Evidencias

La actividad incluye la sincronización del repositorio,
tres conexiones, autenticación por CLI y un volumen
con archivos PDF e imágenes.
